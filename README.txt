ALWAN TV Web
=============
افتح index.html على استضافة ويب.
الموقع لا يحتوي على خادم خاص؛ روابط القنوات مأخوذة من ملف M3U8 الأصلي.
بعض متصفحات الويب قد تحتاج الخادم/الرابط إلى CORS صحيح حتى يعمل البث.
للنشر العام: ارفع index.html إلى استضافة مواقع ثابتة مثل GitHub Pages أو Cloudflare Pages أو استضافة ويب عادية.
